## 🛒 Необходимые компоненты

### Аппаратное обеспечение

| Компонент | Количество | Примечание |
|-----------|------------|------------|
| ESP32 Development Board | 1 | Любая модель (DevKit v1, NodeMCU-32S и т.д.) |
| AHT10 Sensor Module | 1 | Модуль с 4 контактами (VIN, GND, SCL, SDA) |
| USB Micro/Type-C кабель | 1 | Для подключения ESP32 к компьютеру |
| Провода Dupont (Female-Female) | 4 | Для подключения датчика |
| Breadboard (опционально) | 1 | Для удобного монтажа |

### Программное обеспечение

- Arduino IDE (версия 1.8.x или 2.x)
- Драйвер CP2102 или CH340 (обычно устанавливается автоматически)
- Библиотеки: Adafruit AHTX0, Adafruit BusIO

## 💻 Установка Arduino IDE

### Windows

1. Перейдите на [arduino.cc/en/software](https://www.arduino.cc/en/software)
2. Скачайте **Arduino IDE** для Windows
3. Запустите установщик и следуйте инструкциям
4. После установки запустите Arduino IDE

### Linux (Ubuntu/Debian)

```bash
# Скачать и установить из Snap Store
sudo snap install arduino

# Или загрузить с официального сайта
wget https://downloads.arduino.cc/arduino-ide/arduino-ide_latest_Linux_64bit.AppImage
chmod +x arduino-ide_latest_Linux_64bit.AppImage
./arduino-ide_latest_Linux_64bit.AppImage
```

### macOS

1. Перейдите на [arduino.cc/en/software](https://www.arduino.cc/en/software)
2. Скачайте версию для macOS
3. Переместите приложение в папку Applications
4. Запустите Arduino IDE

## 🔧 Настройка ESP32 в Arduino IDE

### Шаг 1: Добавление ESP32 Board Manager URL

1. Откройте Arduino IDE
2. Перейдите в меню:
   - **Arduino IDE 1.x**: `File` → `Preferences`
   - **Arduino IDE 2.x**: `File` → `Preferences` (или `Arduino IDE` → `Settings` на macOS)

3. В поле **"Additional Boards Manager URLs"** добавьте:
   ```
   https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
   ```

4. Нажмите **OK**

### Шаг 2: Установка ESP32 Board Package

1. Откройте Boards Manager:
   - **Arduino IDE 1.x**: `Tools` → `Board` → `Boards Manager`
   - **Arduino IDE 2.x**: Нажмите на иконку **досок** слева

2. В поисковой строке введите: `esp32`

3. Найдите **"esp32 by Espressif Systems"**

4. Нажмите **Install** (установка займет несколько минут)

5. После установки нажмите **Close**

### Шаг 3: Выбор платы ESP32

1. Подключите ESP32 к компьютеру через USB
2. Выберите плату:
   - `Tools` → `Board` → `ESP32 Arduino` → `ESP32 Dev Module`
   
   (или выберите вашу конкретную модель, если она есть в списке)

3. Выберите порт:
   - `Tools` → `Port` → выберите COM-порт с ESP32
   - **Windows**: обычно `COM3`, `COM4` и т.д.
   - **Linux**: `/dev/ttyUSB0` или `/dev/ttyACM0`
   - **macOS**: `/dev/cu.usbserial-xxxxx`

## 📚 Установка библиотек

### Способ 1: Через Library Manager (рекомендуется)

1. Откройте Library Manager:
   - **Arduino IDE 1.x**: `Sketch` → `Include Library` → `Manage Libraries`
   - **Arduino IDE 2.x**: Нажмите на иконку **книг** слева

2. Установите **Adafruit AHTX0**:
   - В поисковой строке введите: `Adafruit AHTX0`
   - Найдите библиотеку **"Adafruit AHTX0"**
   - Нажмите **Install**
   - При появлении запроса установить зависимости, нажмите **Install All**

3. Убедитесь, что установлена **Adafruit BusIO**:
   - Поищите: `Adafruit BusIO`
   - Если не установлена, нажмите **Install**

### Способ 2: Ручная установка

```bash
# Клонируйте репозитории библиотек
cd ~/Documents/Arduino/libraries/

git clone https://github.com/adafruit/Adafruit_AHTX0.git
git clone https://github.com/adafruit/Adafruit_BusIO.git
git clone https://github.com/adafruit/Adafruit_Sensor.git
```

Затем перезапустите Arduino IDE.

## 🔌 Подключение датчика AHT10

### Схема подключения

```
AHT10 Module          ESP32 Board
┌─────────┐          ┌─────────┐
│   VIN   │─────────→│  3.3V   │  (Питание +3.3V)
│   GND   │─────────→│  GND    │  (Земля)
│   SDA   │─────────→│ GPIO 21 │  (Данные I2C)
│   SCL   │─────────→│ GPIO 22 │  (Тактирование I2C)
└─────────┘          └─────────┘
```

### Подробная инструкция

1. **Отключите ESP32** от питания (выньте USB кабель)

2. **Подключите провода** к AHT10:
   - **Красный провод** → VIN (питание)
   - **Черный провод** → GND (земля)
   - **Желтый/Зеленый** → SDA (данные)
   - **Синий/Белый** → SCL (тактирование)

3. **Подключите провода** к ESP32:
   - **VIN** → пин с маркировкой **3.3V** (НЕ 5V!)
   - **GND** → любой пин **GND**
   - **SDA** → пин **GPIO 21** (или D21)
   - **SCL** → пин **GPIO 22** (или D22)

4. **Проверьте соединения**:
   - Убедитесь, что провода надежно закреплены
   - Проверьте, что нет замыканий между контактами
   - Датчик должен быть обращен сенсором (с отверстием) вверх

5. **Подключите ESP32** к компьютеру

### ⚠️ Важные примечания

- ❌ **НЕ подключайте VIN к 5V** — это может повредить датчик!
- ✅ Используйте только **3.3V**
- ✅ Провода должны быть короткими (до 20 см для стабильной работы I2C)
- ✅ Если датчик не определяется, попробуйте поменять местами SDA и SCL

## 📤 Загрузка скетча

### Вариант 1: Базовый пример (тестирование)

1. Откройте файл: `examples/basic-usage/basic-usage.ino`

2. Нажмите **Upload** (стрелка вправо) или `Ctrl+U`

3. Дождитесь завершения компиляции и загрузки

4. Откройте Serial Monitor:
   - `Tools` → `Serial Monitor`
   - Установите скорость: **115200 baud**

5. Вы должны увидеть показания температуры и влажности

### Вариант 2: Веб-сервер (полная версия)

1. Откройте файл: `src/ESP32_AHT10_WebServer/ESP32_AHT10_WebServer.ino`

2. **Измените настройки WiFi**:
   ```cpp
   const char* ssid = "YOUR_WIFI_SSID";        // Имя вашей WiFi сети
   const char* password = "YOUR_WIFI_PASSWORD"; // Пароль от WiFi
   ```

3. Нажмите **Upload** (стрелка вправо)

4. Откройте Serial Monitor (115200 baud)

5. Дождитесь подключения к WiFi и запишите **IP адрес**

6. Откройте браузер и введите этот IP адрес

## 🚀 Первый запуск

### Проверка базового примера

1. После загрузки `basic-usage.ino` откройте Serial Monitor

2. Вы должны увидеть:
   ```
   =================================
   ESP32 + AHT10 - Базовый пример
   =================================
   Инициализация AHT10... OK!
   Датчик успешно инициализирован!
   
   Начинаю считывание данных...
   ---------------------------------
   Температура: 23.4 °C  |  Влажность: 56.2 %
   Уровень комфорта: ✓ КОМФОРТНО
   ---------------------------------
   ```

3. Если всё работает — переходите к веб-серверу!

### Запуск веб-сервера

1. Загрузите `ESP32_AHT10_WebServer.ino`

2. В Serial Monitor найдите строку:
   ```
   WiFi подключен!
   IP адрес: 192.168.1.XXX
   ```

3. Откройте браузер и введите этот IP адрес

4. Вы увидите веб-интерфейс с данными датчика!

5. Данные обновляются автоматически каждые 2 секунды

### Доступ к JSON API

Для интеграции с другими системами используйте:
```
http://192.168.1.XXX/data
```

Ответ:
```json
{
  "temperature": 23.45,
  "humidity": 56.78
}
```

## 🔧 Решение проблем

### Проблема 1: ESP32 не определяется в системе

**Симптомы:**
- COM-порт не появляется в списке
- Windows не видит устройство

**Решение:**
1. Установите драйвер CP2102 или CH340:
   - **CP2102**: [silabs.com/developers/usb-to-uart-bridge-vcp-drivers](https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers)
   - **CH340**: [sparks.gogo.co.nz/ch340.html](http://www.wch.cn/downloads/CH341SER_ZIP.html)

2. Попробуйте другой USB кабель (некоторые кабели только для зарядки)

3. Попробуйте другой USB порт

4. Перезагрузите компьютер

### Проблема 2: Ошибка при загрузке скетча

**Симптомы:**
```
Failed to connect to ESP32: Timed out waiting for packet header
```

**Решение:**
1. Зажмите кнопку **BOOT** на ESP32
2. Нажмите **Upload** в Arduino IDE
3. Держите **BOOT** до появления "Connecting..."
4. Отпустите **BOOT**

### Проблема 3: AHT10 не найден

**Симптомы:**
```
Не удалось найти датчик AHT10
```

**Решение:**
1. Проверьте подключение проводов:
   - VIN → 3.3V (не 5V!)
   - GND → GND
   - SDA → GPIO 21
   - SCL → GPIO 22

2. Попробуйте поменять местами SDA и SCL

3. Проверьте качество контактов (пропаяйте, если нужно)

4. Измените I2C адрес (для некоторых модулей):
   ```cpp
   if (!aht.begin(0x38)) { // Попробуйте 0x38 вместо дефолтного
   ```

5. Добавьте подтягивающие резисторы 4.7кОм на SDA и SCL к 3.3V

### Проблема 4: WiFi не подключается

**Симптомы:**
```
Подключение к WiFi........[много точек]
```

**Решение:**
1. Проверьте правильность SSID и пароля (регистр важен!)

2. Убедитесь, что ESP32 в зоне действия WiFi

3. Проверьте, что WiFi работает на частоте 2.4 GHz (ESP32 не поддерживает 5 GHz)

4. Попробуйте добавить задержку перед подключением:
   ```cpp
   delay(1000);
   WiFi.begin(ssid, password);
   ```

5. Добавьте отладку:
   ```cpp
   WiFi.onEvent([](WiFiEvent_t event) {
     Serial.printf("WiFi event: %d\n", event);
   });
   ```

### Проблема 5: Веб-страница не открывается

**Симптомы:**
- Serial Monitor показывает IP адрес
- Браузер не может открыть страницу

**Решение:**
1. Убедитесь, что компьютер и ESP32 в одной сети

2. Попробуйте пинговать ESP32:
   ```bash
   ping 192.168.1.XXX
   ```

3. Проверьте firewall (временно отключите для теста)

4. Попробуйте другой браузер

5. Перезагрузите ESP32 (кнопка EN или отключите/подключите питание)

### Проблема 6: Неправильные показания

**Симптомы:**
- Температура = 0.0 или -40.0
- Влажность = 0.0

**Решение:**
1. Датчик может быть неисправен — попробуйте другой AHT10

2. Проверьте питание (должно быть стабильное 3.3V)

3. Добавьте задержку после инициализации:
   ```cpp
   aht.begin();
   delay(100); // Дайте датчику время стабилизироваться
   ```

4. Попробуйте сбросить датчик программно:
   ```cpp
   aht.begin();
   delay(100);
   aht.getEvent(&humidity, &temperature); // Первое чтение может быть неточным
   delay(100);
   ```

## 📊 Тестирование и калибровка

### Проверка точности

1. Положите датчик рядом с термометром
2. Сравните показания через 5-10 минут (датчику нужно время на стабилизацию)
3. Допустимая погрешность AHT10:
   - Температура: ±0.3°C
   - Влажность: ±2%

### Рекомендации по установке

- ✅ Устанавливайте датчик вдали от источников тепла
- ✅ Избегайте прямых солнечных лучей
- ✅ Обеспечьте хорошую циркуляцию воздуха
- ✅ Не закрывайте вентиляционное отверстие датчика
- ❌ Не устанавливайте рядом с ESP32 (он нагревается)

## 🎓 Дополнительные настройки

### Изменение частоты обновления

В скетче измените задержку:
```cpp
delay(2000); // 2 секунды (2000 мс)
```

На:
```cpp
delay(5000); // 5 секунд
delay(1000); // 1 секунда (минимум рекомендуется)
```

### Изменение порта веб-сервера

По умолчанию используется порт 80:
```cpp
WebServer server(80);
```

Можно изменить на другой:
```cpp
WebServer server(8080);
```

Тогда адрес будет: `http://192.168.1.XXX:8080`

### Статический IP адрес

Замените эту часть в `setup()`:
```cpp
WiFi.begin(ssid, password);
```

На:
```cpp
IPAddress local_IP(192, 168, 1, 184); // Желаемый IP
IPAddress gateway(192, 168, 1, 1);    // Шлюз вашего роутера
IPAddress subnet(255, 255, 255, 0);

WiFi.config(local_IP, gateway, subnet);
WiFi.begin(ssid, password);
```

## 🔒 Безопасность

### Рекомендации

- ❌ Не размещайте ESP32 в интернете напрямую без защиты
- ✅ Используйте только в локальной сети
- ✅ Для доступа из интернета используйте VPN
- ✅ Не храните пароли WiFi в публичных репозиториях

### Скрытие учетных данных

Создайте файл `secrets.h`:
```cpp
// secrets.h
#define WIFI_SSID "your_ssid"
#define WIFI_PASSWORD "your_password"
```

В основном скетче:
```cpp
#include "secrets.h"
const char* ssid = WIFI_SSID;
const char* password = WIFI_PASSWORD;
```

Добавьте в `.gitignore`:
```
secrets.h
```
